# 북톡 사이트 작업 스킬

책을 미리 읽고, 별점으로 고르고, 함께 이야기하는 독서 커뮤니티 **북톡**의 정적 웹사이트.
빌드 도구 없이 순수 HTML · CSS · JavaScript로 만들고, 브라우저에서 `index.html`을 바로 열어 확인한다.

- 프로젝트 폴더: `C:\Users\SBS\Desktop\프로젝트 북톡 사이트 만들기`
- GitHub: https://github.com/whchoi1998-lgtm/Project-booktalk.git (브랜치 `main`)

## 1. 꼭 지킬 규칙

### 폴더 · 파일
- 메인 화면은 **`index.html`**(최상위), 그 외 페이지는 모두 **`html/`** 폴더에 둔다.
- CSS와 JS는 반드시 분리한다. 페이지마다 같은 이름의 짝을 만든다.
  `html/club.html` → `css/club.css` + `js/club.js`
- 여러 페이지가 함께 쓰는 것은 **`css/common.css`**, **`js/common.js`**에 둔다.
  두 페이지 이상에서 쓰게 되면 페이지 전용 파일에서 공통 파일로 옮긴다.
- 샘플 데이터는 **`js/data.js`** 한 곳에 모은다. 페이지 전용 데이터가 많으면 `js/페이지-data.js`로 분리한다(예: `community-new-data.js`).
- 이미지: `img/logo.svg`(로고), 책 표지는 **`img/분야폴더/책 제목.확장자`**
  - 분야폴더: `소설` `에세이` `인문` `경제경영` `과학` `자기계발` ("경제 경영"은 주소 문제로 띄어쓰기 없이)
- `md/` 폴더: 이 스킬 문서 같은 정리 문서.

### 코드 스타일
- 주석 · 화면 문구는 **한국어**. 파일 맨 위에 그 파일이 맡는 일을 블록 주석으로 적는다.
- CSS 클래스는 BEM 비슷하게: `.book-card`, `.book-card__title`, `.btn--primary`, 상태는 `.is-open`, `.is-on`.
- 색 · 글꼴 · 간격은 `common.css`의 `:root` 변수를 쓴다 (아래 디자인 토큰).
- JS는 `document.addEventListener('DOMContentLoaded', ...)` 안에서 시작하고, 이벤트는 위임(부모에 한 번)으로 처리한다.
- 사용자 입력을 화면에 넣을 때는 반드시 `escapeHTML()`을 거친다.
- `localStorage`는 항상 `try/catch`로 감싼다 (막힌 환경에서도 페이지는 동작해야 함).
- 링크 경로는 `common.js`의 `ROOT`/`pagePath()`로 만든다 (최상위·html 폴더 어디서든 맞는 경로).

### 새 서브 페이지 만들 때
- 상단 최상단 바 · 헤더 · 푸터 · 미리보기 모달은 `html/books.html`과 **똑같이** 복사해 쓴다.
- 메뉴에서 현재 페이지에는 `aria-current="page"`를 붙인다 (주황 글자 + 밑줄로 표시됨).
- 페이지 제목 띠는 공용 `.page-head` (위치 표시 `.breadcrumb` + 제목 + `.page-stats` 통계 카드).

### 커밋 · 푸시
- 커밋 메시지는 **`verX.YY`** 형식, 0.01씩 올린다. 사용자가 번호를 말하면 그 번호를 쓴다.

## 2. 사용자 선호 (대화에서 확인된 것)

- 요청은 짧게 "수정사항이 있어 ~해줘" 형태로 온다. 참고 이미지(다른 사이트 캡처, 와이어프레임)를 자주 보낸다 → **이미지를 최대한 그대로** 따른다.
- 결과 설명은 **한국어로, 무엇이 어디서 어떻게 바뀌었는지** 정리해서 알려준다. 수정한 파일 링크를 함께 준다.
- 필수 기능 외에 "기본적인 요소는 알아서 챙겨" 주는 것을 좋아한다. 단, 요청 범위를 크게 넘는 변경은 먼저 말한다.
- 디자인은 **대중적으로 유명한 사이트 · 디자이너들이 쓰는 레이아웃**을 선호한다 (커뮤니티 리뉴얼 요청).
- 새 디자인을 시도할 때는 기존 파일을 덮지 않고 **새 html로 샘플**을 만들어 비교하게 한다 (`community-new.html`).
- 가상의 책이 실제 이미지와 안 맞으면 싫어한다 → 표지는 **책 제목에 맞게** 만든다.

## 5. 공용 코드 (`js/common.js`)

| 이름 | 하는 일 |
|---|---|
| `ROOT`, `pagePath(file)` | 현재 페이지 위치에 맞는 상대 경로 |

| `escapeHTML()`, `starsHTML()`, `coverHTML()`, `bookCardHTML()` | 화면 조각 (카드 전체가 상세 링크, 미리보기 버튼은 위에) |
| `openPreview(id)` | 첫 장 미리보기 모달 (`[data-preview]` 클릭 시 자동) |
| `clubCardHTML()`, `clubState()`, `toggleClubJoin()`, `dday()`, `joinedClubs` | 독서모임 카드 · 신청 저장 |
| `showToast(msg)` | 하단 알림 |

### 데이터 (`js/data.js`)
- `CATEGORIES` 7개(전체 포함), `BOOKS` 16권(전부 **가상의 책**, 미리보기 본문도 창작), `CLUBS` 6개, `POST_TYPES` · `COMMUNITY_POSTS`, `SAMPLE_REVIEWS` · `DISCUSSION_QUESTIONS` · `SAMPLE_OPINIONS`.
- 표지: `COVER_FOLDERS`로 `img/분야/제목.svg`를 자동 지정. 다른 파일은 책에 `cover: '경로'`로 직접.
- **실제 책 내용 · 저작권 있는 문장은 넣지 않는다.**

`booktalk-book-requests`, `booktalk-reviews-<id>`, `booktalk-opinions-<id>`, `booktalk-joined-clubs`, `booktalk-posts`, `booktalk-post-likes`, `bt-cm-*`(리뉴얼 커뮤니티)

- **SNS 링크**: 카카오톡 · 인스타그램 `href="#"` → 실제 주소 받으면 모든 페이지에서 교체.
- `img/자기계발/말 잘하는 사람의 듣기.png`(사용자가 준 다른 책 표지)는 사용 안 함 — 삭제 여부 확인 필요.
- 서버가 없으므로 신청 · 글 · 댓글 · 공감은 브라우저에만 저장됨을 항상 안내.

## 8. 이 문서 업데이트 방법

작업이 며칠 · 몇 주 쌓이면 사용자가 "스킬파일 업데이트 해줘"라고 요청한다. 그때:
1. 맨 위 `updated:` 날짜를 바꾼다.
2. **6. 작업 기록**에 새 요청 · 결과를 날짜와 함께 이어 적는다.
3. 새로 확정된 디자인 결정은 **2.** 표에, 새 페이지 · 파일은 **4. · 5.**에 반영한다.
4. **1. 커밋** 항목의 "다음 버전 번호"와 **7. 남은 일**을 최신으로 고친다.
5. 사실과 달라진 내용(파일 이름, 함수 이름 등)은 실제 코드를 확인한 뒤 고친다.
